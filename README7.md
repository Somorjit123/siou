# Python Programming 

# 📌 Task 07: Object-Oriented Programming (OOP) & Employee Management System

## 🎯 Objective

The purpose of this task is to understand **Object-Oriented Programming (OOP)**, one of the most important concepts in Python used in real-world software development.

This project demonstrates the use of **classes, objects, constructors, lists, file handling, and menu-driven programming** by developing an **Employee Management System**.

---

## 🛠 Features

The Employee Management System provides the following functionalities:

- ➕ Add Employee
- 📋 View All Employees
- 🔍 Search Employee by ID
- 🔍 Search Employee by Name
- ✏️ Update Employee Details
- ❌ Delete Employee
- 💰 Display Salary Statistics
- 📁 Export Employee Data to CSV/TXT
- 📖 Read and Display Saved Employee Records
- 🚪 Exit Program

---


## ⭐ Object-Oriented Concepts Used

This project demonstrates the following OOP concepts:

- Class
- Object
- Constructor (`__init__`)
- Instance Variables
- Methods
- Encapsulation
- List of Objects
