# Part A: Even or Odd Checker

### Files

* `even_odd.py`
* `even_odd.c`

### Description

This program accepts a number from the user and determines whether it is even or odd.

### Sample Output

```text
Enter a Number: 15
15 is an Odd Number
```

# Part B: Largest of Three Numbers

### Files

* `largest_number.py`
* `largest_number.c`

### Description

This program takes three numbers as input and finds the largest number among them.

### Sample Output

```text
Enter First Number: 10

```

# Part C: Student Grade Calculator

### Files

* `grade_calculator.py`
* `grade_calculator.c`

### Description

This program accepts marks from the user and displays the corresponding grade.

| Marks    | Grade |
| -------- | ----- |
| 90 – 100 | A     |
| 80 – 89  | B     |
| 70 – 79  | C     |
| 60 – 69  | D     |
| Below 60 | F     |

### Sample Output

```text
Enter Marks: 85
Grade: B
```

# Part D: Simple Login Validation

### Files

* `login_validation.py`
* `login_validation.c`

### Description

This program validates a username and password entered by the user against predefined credentials.

### Default Credentials

```text
Username: admin
Password: password123
```

### Sample Output

```text
Enter Username: admin
Enter Password: password123

Login Successful
```

### Invalid Login Example

```text
Invalid Credentials
```

# Part E: Password Strength Checker

### Files

* `password_checker.py`
* `password_checker.c`

### Description

This program evaluates password strength based on:

* Minimum length of 8 characters
* At least one uppercase letter
* At least one numeric digit

### Strength Levels

* Weak Password
* Moderate Password
* Strong Password

### Sample Output

```text
Password: Cyber123

Strong Password
```
