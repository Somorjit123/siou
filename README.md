# Python Programming 

## 📌 Task 05: Arrays, Lists & Data Processing

### 🎯 Objective

The purpose of this task is to understand how data is stored, processed, searched, and analyzed using Lists in Python. These concepts are widely used in software development, automation, and cybersecurity applications.

---

## 📂 Program Features

### Part A: Student Marks Analyzer

* Accepts marks of 5 students.
* Stores marks in a list.
* Displays:

  * Highest Marks
  * Lowest Marks
  * Average Marks

### Part B: Employee Record Search

* Stores employee names in a list.
* Allows the user to search for a name.
* Displays:

  * Record Found
  * Record Not Found

### Part C: Number Statistics Tool

* Accepts 10 numbers from the user.
* Displays:

  * Largest Number
  * Smallest Number
  * Sum
  * Average
  * Count of Even Numbers
  * Count of Odd Numbers

### Part D: Cyber Security Log Analyzer

* Stores login attempt records.
* Displays:

  * Total Login Attempts
  * Successful Logins
  * Failed Logins
* Explains the importance of monitoring failed login attempts.

### Part E: Blacklisted IP Checker

* Stores blacklisted IP addresses.
* Allows the user to search for an IP address.
* Displays:

  * IP Found in Blacklist
  * IP Not Found

---

## ▶️ How to Run

1. Install Python 3.
2. Save the program as `task05.py`.
3. Open Terminal or Command Prompt.
4. Run the command:

```bash
python task05.py
```
