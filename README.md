# Python and C Programming

## 📌 Task 04: Functions, File Handling & Student Management System

### 🎯 Objective

The purpose of this task is to understand functions, modular programming, file handling, and basic data management concepts. All programs were implemented in both Python and C Programming.

---
## 🔹 Part A: Calculator Using Functions

### Description

A menu-driven calculator that performs:

* Addition
* Subtraction
* Multiplication
* Division

### Functions Used

* add()
* subtract()
* multiply()
* divide()

### Concepts Learned

* Functions
* Return Statements
* Menu-Driven Programming

---

### Functions Used

* display_student_info()

### Concepts Learned

* Data Organization
* Structured Programming

## 🔹 Part C: Marks Analysis System

### Description

Accepts marks for 5 subjects and calculates:

* Total Marks
* Percentage
* Grade

### Grade Criteria

| Percentage | Grade |
| ---------- | ----- |
| 90+        | A     |
| 80+        | B     |
| 70+        | C     |
| 60+        | D     |
| Below 60   | F     |

### Concepts Learned

* Functions
* Conditional Statements
* Percentage Calculation
