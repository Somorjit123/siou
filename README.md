* Count of even numbers
* Count of odd numbers

### Example

**Input**

```
40
```

**Output**

![Image Alt](https://github.com/Somorjit123/siou/blob/e0383983238ce4d7338b73ae5b33c223e3c7b193/Programming_Task_03_somorjit/screenshot/number_analysis.png)
